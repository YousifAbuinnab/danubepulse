# Demo fixture provenance

These small records are fabricated solely for local demonstrations and tests. They
are not Austrian observations, forecasts, market prices, or measurements from any
named station. The CC0 label applies only to these fabricated fixtures. Data source
rows, API results, and the dashboard label them `synthetic`; live data is never
merged into these records. The river fixture intentionally includes a duplicate,
a one-hour gap, and a separate changed-schema record to exercise quality checks and
incident replay.
